# SQL Retail Store Analysis Project

## Overview
A relational database built to track online store operations, customer details, product inventories, and sales orders. 

## Tech Stack
* SQL Server Management Studio (SSMS) / T-SQL

## Key Skills Demonstrated
* Creating relational databases and tables with Primary/Foreign keys.
* Using table aliases for clean, readable multi-table queries.
* Performing `INNER JOIN` and `LEFT JOIN` operations.
* Aggregating data using `SUM`, `COUNT`, and `GROUP BY`.
* Sorting and filtering data with `ORDER BY`.
